# miele-system
O Miele System é um gestor empresarial da Compasse para clientes e PER/DCOMPs. API-first em Django/DRF, com autenticação JWT+2FA, RBAC, auditoria imutável, anexos em S3, observabilidade (logs JSON, Sentry) e backoffice seguro em Django Admin com dashboards, aprovações e gestão centralizada.
